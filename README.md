# pypvz 白天实验室 V3.1

这是一个基于《植物大战僵尸》的策略测试环境。真人和AI通过同一套游戏动作规则进行种植、铲除与等待，过程可以记录、比较和回放。本项目主要用于小组测试与分析，不以制作完整商业游戏或扩充原版全部玩法为目标。

## 给组长的项目概览

当前已实现 **10档僵尸难度 × A／B／C三套植物组合，共30种可选择的实验条件**。这不意味着第二组同学需要把30种条件全部玩完，也不意味着10档关卡都会进入正式测试。

这套关卡的主要用途是：先提供由低到高的候选难度梯度，第二组同学通过实际试玩检查难度变化是否平滑，再从中挑选几个适合的关卡，作为后续的基准测试条件。第二组在统一条件下游玩，结合操作记录、回放和主观感受完成分析。

目前已完成的是关卡与记录工具，具体的关卡选择由第二组试玩后确认。关卡编号表示设计上的压力梯度。

|概念|含义|需要避免的误解|
|---|---|---|
|关卡01—10|改变僵尸数量、种类和波次组合的十档候选难度|不是必须依次通关的课程任务|
|方案A／B／C|三套不同的固定8卡植物组合|不是三档难度，也不是三个小组的编号|
|30种条件|十档关卡与三套卡组组合后的可选范围|不是30场必做测试|
|基准测试条件|试玩筛选后锁定的关卡、卡组、种子、版本及运行方式|不只是一个关卡编号|


## A／B／C方案分别测试什么

三套方案提供不同的可用工具，便于观察玩家如何安排经济、过渡输出、防守和应急处理。每局固定提供8张卡，但不要求全部使用，也不要求主题植物必须成为主力。

|卡位|A：豌豆火力成长|B：寒冰控制防守|C：大喷菇群攻防线|
|---|---|---|---|
|1|向日葵|向日葵|向日葵|
|2|豌豆射手|寒冰射手|大喷菇|
|3|双发射手|豌豆射手|咖啡豆|
|4|三线射手|杨桃|豌豆射手|
|5|火炬树桩|高坚果|胆小菇|
|6|坚果|地刺|坚果|
|7|土豆地雷|窝瓜|窝瓜|
|8|樱桃炸弹|火爆辣椒|毁灭菇|

- **方案A**：提供基础射击、火炬增伤和多行输出，可观察火力建设与经济投入的取舍。
- **方案B**：提供减速、阻挡与不同攻击方式，可观察控制、防守和持续伤害的组合。
- **方案C**：提供蘑菇输出及豌豆过渡。白天的大喷菇、胆小菇、毁灭菇默认休眠，需要额外种植咖啡豆并等待唤醒，涉及额外费用、操作与冷却安排。

方案名称是对卡组特点的描述，不是对玩家风格的预先判定。选择A不等于“激进”，选择B不等于“保守”。分析偏好时，应依据实际种了什么、何时种、花了多少资源，以及玩家自己的解释。

同档关卡、同种子下，三套方案使用相同出怪安排。但这不保证三套卡组难度或胜率相同；比较方案本身就是在观察不同工具组合带来的差异。

## 如何启动与使用

Windows首次下载：

1. 安装Python 3.12（包含Python Launcher），下载并解压完整仓库，保留素材目录。
2. 双击 `setup_day_lab.cmd` 创建独立运行环境。
3. 双击 `start_day_lab.cmd`，选择关卡01—10、方案A／B／C、控制者和种子。所有关卡直接开放，无需解锁。

真人游玩不需要API密钥。鼠标点击卡片再点草地，或按数字键1—8选卡；右键取消，S铲除，P暂停，Esc结束并保存。详细规则、回放与自定义配置见 [使用说明](README_DAY_LAB.md)。
