# 白天实验室 V3 使用说明

## 开始与操作

双击 start_day_lab.cmd，选择关卡01—10、方案A/B/C、控制者和种子，默认01-A、真人、种子42。八张卡均可用，不要求全部种植，也不强制主题植物成为主力。

点击卡片再点草地，或1—8选卡；右键取消。S铲除且不退款，Enter等待，P人工暂停，Esc结束保存，练习模式R重开。界面行列从1开始，API从0开始。人工干预会标记。

大喷菇、胆小菇、毁灭菇白天默认休眠，需要在原格另种咖啡豆。含咖啡成本分别150、100、200阳光，所有蘑菇共用咖啡卡冷却。空格、已清醒或正在唤醒的蘑菇不能再种咖啡。
毁灭菇留下约180秒不可种植的弹坑。土豆地雷需约15秒准备；杨桃不向正右方直射；火炬转换寒冰弹会去掉减速。

## 记录、回放和比较

示例目录：experiments/关卡06/方案C/20260928-150000_agent-cloud_seed42_e5f6a7b8。
human为真人、agent-cloud为云端、agent-rule为规则控制器。独立编号避免覆盖；模型详情保存在清单和model_config中。

入口支持关卡／方案／控制者筛选，Ctrl多选比较；中断记录也保存。同方案人机比较要求同完整游戏条件，跨方案比较要求同环境和控制器配置，均检查版本、时间模式及干预状态。实时真人与暂停思考Agent不能视为相同时间条件。研究范围是策略决策，不代表感知体验完全相同。

选择记录及秒数回放，空格播放／暂停、左右键跳转、+/-调速。回放从开局执行已保存动作，不调用模型。正常验证要求代码、依赖与素材指纹匹配；跨版本检查不宣称同版本验证。

## 云端配置与暂停

复制 cloud.deepseek.example.json 为 cloud.local.json，填写服务与模型，在本机设置 PVZ_API_KEY 环境变量。启动终端示例：

```powershell
$env:PVZ_API_KEY = "你的密钥"
.\.venv\Scripts\python.exe -B -m daylab
```

DeepSeek示例使用思考low（仍开启思考并在思考期间暂停游戏）、120秒总超时、输出8192、整局最多600请求及300万累计Token预算。提示词要求少量候选、一次合法性检查和简短备忘，不反复规划整局；这不是思考Token的硬上限，仍保留截断恢复。修改配置或提示词后请开始新对局。max_output_tokens是单次输出，不是总上下文；填写整数，不填“128K”。context_window_tokens与provider_max_output_tokens独立表示模型总上下文与服务允许输出上限，更换模型时按其说明配置。

公开状态提供当前／总波数、时间上限及剩余时间；真人画面时间显示为“已用／上限秒”。全部波次敌人消灭且守住家园才获胜，超时不算胜利。文字棋盘直接标注蘑菇“睡／唤醒中／醒”、胆小菇“退缩”和地雷“准备／就绪”；睡眠或唤醒中的蘑菇不能算当前火力。不提供未来出怪表或隐藏血量。游戏风格仍单独在prompts/play_style.json编辑。

输入默认估算上限32768，目前未捆绑服务商分词器，使用UTF-8字节加固定余量的保守估算；实际Token以服务usage为准。超限先去掉最旧历史帧，再去掉最旧事实，始终保留当前完整局面、规则和限长策略；仍超限则暂停。
正常带最近5秒每秒一帧、最多20条事实和400字策略，不累积整局对话。实际裁剪量写入diagnostics。

一次决策最多初次＋一次追加请求，纠错与网络重试共用机会。授权／余额／参数错误直接暂停；连续三次决策失败也暂停。点击“重试并继续”或T，Esc结束保存。暂停不推进游戏，恢复不补算等待时间。
预算不足需要结束并调整新局配置，重试不会绕过上限。输出截断仅在已配置模型限额及整局预算允许时把该次额度提高至16384。未知用量单独预留，不当作已确认消费；终局取消不代表服务端取消计费。
思考模式下，推理Token也可能占用单次输出额度，导致没有剩余额度生成最终动作；这种情况按finish_reason=length记录为输出截断，不误记为普通JSON错误或输入过长。

无窗口命令行暂停时，交互终端可输入r重试；没有交互输入则以technical_error保存退出。桌面版保持暂停等待处理。
编辑prompts/play_style.json调整风格，prompts/cloud_framework.md保留框架接口；修改后开始新局，运行期间不热更新。

## 命令

```powershell
.\.venv\Scripts\python.exe -B -m daylab run --level 06 --scheme C --actor human --seed 42
.\.venv\Scripts\python.exe -B -m daylab run --level 06 --scheme C --actor cloud --cloud-config cloud.local.json
.\.venv\Scripts\python.exe -B -m daylab run --level 10 --scheme B --actor rule --headless --fast
.\.venv\Scripts\python.exe -B -m daylab replay "单局完整目录" --verify
.\.venv\Scripts\python.exe -B -m daylab compare "第一局目录" "第二局目录" --output reports/my-comparison
```

发生问题先查看该局model_results、model_state与errors。libpng颜色配置警告本身不表示崩溃。开发接口和数据契约见docs中的说明。
