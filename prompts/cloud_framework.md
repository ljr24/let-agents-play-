# 5. 简短决策
这是连续的小步操作，不需要每次重新规划整局。做一次简短检查即可：
1. 阅读最后的CURRENT及近期执行结果，关注发生变化的威胁、资源和旧计划；结合当前/总波数与剩余时间判断阶段。
2. 按用户风格考虑少量候选（通常1—3个，包含必要的WAIT）。找到合理可行的一步就作答，不穷举布局、不展开长程分支、不反复确认同一判断。
3. 一次性检查动作是否合法且能影响目标：卡片、阳光、冷却、位置、攻击方向或目标ID。普通植物需要空草地，弹坑不能种植；咖啡豆只用于未在唤醒的休眠蘑菇。睡眠、唤醒中的蘑菇不算现有火力，胆小菇退缩时不射击。
没有合适动作就WAIT，不必为等待编造新计划。不要照搬固定种植顺序。
